# 📖 粤语高频词汇：把普通话「换皮」成粤语

> 粤语和普通话语法高度相似，**你缺的不是语法，是「替换词表」**。
> 把下面这些高频替换背熟，你说的话立刻有粤语味。
> 每个词都可以去 [words.hk](https://words.hk/) 听真人发音（强烈建议边听边跟读）。

## 三、数字与钱（买东西必备）

| 数字 | 粤拼 | 数字 | 粤拼 |
| --- | --- | --- | --- |
| 一 | jat1 | 六 | luk6 |
| 二/两 | ji6 / loeng5 | 七 | cat1 |
| 三 | saam1 | 八 | baat3 |
| 四 | sei3 | 九 | gau2 |
| 五 | ng5 | 十 | sap6 |

- 一百 jat1 baak3 ／ 一千 jat1 cin1 ／ 一万 jat1 maan6
- 十蚊 sap6 man1（十块钱，「蚊」= 块）；两蚊鸡 = 两块钱（口语）
- 平 peng4 = 便宜；贵 gwai3 = 贵；「平啲得唔得？」= 能便宜点吗？

## 五、「唔该」vs「多谢」：粤语第一课代表

- **唔该 m4 goi1**：谢谢你的**服务/帮忙**（服务员上菜、别人让路、请人帮忙时）——一天能用 50 次；
- **多谢 do1 ze6**：谢谢你的**赠与/好意**（收礼物、收红包、被夸奖时）。

> 记不住就先全用「唔该」，错不到哪去。
