## 二、港剧 / 电影（先中字 → 粤字 → 无字幕）

**推荐顺序按「对话生活化程度」排：**

| 类型 | 推荐 | 为什么 |
| --- | --- | --- |
| TVB 职场/生活剧 | 《新闻女王》《壹号皇庭》《栋笃神探》 | 日常对话密度最高，语速适中 |
| 港式喜剧 | 周星驰系列（《食神》《喜剧之王》） | 台词地道、重复观看不腻，金句自带记忆点 |
| 文艺片 | 王家卫《花样年华》《重庆森林》 | 慢节奏、台词清晰，适合精听 |

**三遍看法**：
1. 第一遍中字：理解剧情，标记听到的高频词（唔该/点解/咁样…）；
2. 第二遍粤字/无字：专注「听」，验证能听懂多少；
3. 挑一个 2 分钟名场面做**影子跟读**，模仿到语气词都一样。

## 三、粤语歌（练声调最快乐的方式）

| 歌手 | 入门曲目 | 特点 |
| --- | --- | --- |
| Beyond | 《海阔天空》《光辉岁月》 | 咬字最清晰，传唱度最高，粤语歌第一课 |
| 陈奕迅 | 《浮夸》《富士山下》 | 词曲俱佳，进阶练听 |
| 张国荣 | 《风继续吹》《倩女幽魂》 | 慢歌多、发音标准 |
| 谭咏麟 | 《朋友》《爱在深秋》 | 经典老歌，节奏友好 |

- 用 **雷猴粤语** App 看粤拼歌词跟唱；
- 唱歌时声调是「送分题」——旋律基本贴着声调走，唱会 10 首歌，声调感自然建立；
- 建一个粤语歌单当日常 BGM，通勤时间全利用起来。

## ✅ 沉浸阶段建议

1. **每天固定「一集剧 + 一首歌」**，三个月后回头看第一集，你会震惊于自己的进步；
2. **优先广州话/香港话**（高度互通），别纠结地区差异；
3. 听到不会的词 → 立刻 words.hk 查 → 存进自己的生词表（每周回顾一次）；
4. 敢说比说对重要：找广东朋友用蹩脚粤语聊天，是最快的校准器。
