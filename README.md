> **难度 ⭐⭐（对普通话母语者较易）**：语法和普通话高度相似，词汇大量相通，
> 真正的难点只有两处——**发音（九声六调）** 和 **地道用词**。
> 本目录下的教程就是为了让你**在这个仓库里直接学会**这两件事，外部资源只做补充。

## 🗺️ 学习路径

```
第 1–2 周   ① 发音教程（每天 30 分钟，words.hk 跟读）
第 3–4 周   ② 词汇替换 + ③ 语法 8 点（每天 5 词 + 1 个语法点）
第 2 个月起  ④ 沉浸：每天一集港剧 + 一首粤语歌
持续        找广东/香港朋友聊，或跟读港剧片段
```

## 🎧 随手听音三件套

学粤语全程离不开「听真人读」，把这三个加入收藏夹：

1. **[words.hk 粤典](https://words.hk/)** —— 查任何字词的粤拼 + 真人发音（网页即用）；
2. **有道词典 App** —— 查词点喇叭选粤语发音，手机上最快；
3. **[Forvo 粤语](https://zh.forvo.com/languages/yue/)** —— 同一个词听多位母语者读。
