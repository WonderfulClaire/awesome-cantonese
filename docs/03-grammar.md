# 🧩 粤语语法：和普通话的 8 个不同

> 好消息：粤语语法 90% 和普通话一致，主谓宾、修饰语顺序都一样。
> 这一章只讲**真正不同的 8 处**——学完它们，你就能造出「像样」的粤语句子。

## 1️⃣ 副词后置：「你先走」→「你行先」

粤语习惯把「先」「多/少」「够」放在动词**后面**：

| 普通话 | 粤语 |
| --- | --- |
| 你**先**走 | 你行**先** nei5 haang4 sin1 |
| **多**吃一点 | 食**多**啲 sik6 do1 di1 |
| **少**说两句 | 讲**少**两句 gong2 siu2 loeng5 geoi3 |

## 2️⃣ 双宾语反序：「给我一本书」→「畀本书我」

普通话「给 + 人 + 物」，粤语是「畀 + 物 + 人」：

| 普通话 | 粤语 |
| --- | --- |
| 给**我**一本**书** | 畀本**书我** bei2 bun2 syu1 ngo5 |
| 给**他**钱 | 畀**钱佢** bei2 cin2 keoi5 |

## 3️⃣ 比较句：「比他高」→「高过佢」

| 普通话 | 粤语 |
| --- | --- |
| 我**比他**高 | 我高**过**佢 ngo5 gou1 gwo3 keoi5 |
| 今天**比昨天**热 | 今日热**过**寻日 gam1 jat6 jit6 gwo3 cam4 jat6 |

结构：**A + 形容词 + 过 + B**。

## 4️⃣ 动词体貌标记：咗 / 紧 / 过 / 开

粤语用动词后缀表达「完成/进行/经历/习惯」，比普通话更规整：

| 标记 | 含义 | 例句 |
| --- | --- | --- |
| **咗 zo2** | 完成（≈了） | 我食**咗**饭 = 我吃**了**饭 |
| **紧 gan2** | 进行（≈正在） | 我食**紧**饭 = 我**正在**吃饭 |
| **过 gwo3** | 经历（≈过） | 我食**过**呢间嘢 = 我吃**过**这家 |
| **开 hoi1** | 一直/习惯 | 我饮**开**呢款茶 = 我一直喝这款茶 |

## 5️⃣ 「有 + 动词」表完成确认

粤语可以直接说「有冇 + 动词」提问、「有 + 动词」回答，普通话没有这个用法：

- 你**有冇**食饭？（你吃饭了没有？）
- **有**食。（吃了。）／ **冇**食。（没吃。）

## 6️⃣ 疑问句靠「A 唔 A」和句尾语气词

- 去**唔**去啊？（去不去？）
- 系**唔**系？／系**咪**？（是不是？）
- 得**唔**得？（行不行？）

## 7️⃣ 句尾语气词：粤语的灵魂调味料

粤语句尾语气词比普通话丰富得多，先掌握这 6 个：

| 语气词 | 功能 | 例句 |
| --- | --- | --- |
| 啊 aa3 | 缓和语气（最百搭） | 系啊、好啊 |
| 喇 laa3 | 已然/提醒（≈了） | 食饭喇！（吃饭啦！） |
| 咩 me1 | 惊讶反问（≈吗？） | 你唔知咩？（你不知道吗？） |
| 啩 gwaa3 | 猜测（≈吧） | 系啩。（是吧。） |
| 啫 ze1 | 而已/轻描淡写 | 好细件啫。（很小件而已。） |
| 㗎 gaa3 | 强调事实 | 好贵㗎！（真的很贵！） |

> 学语气词最好的方式是看港剧模仿，硬背不如多听。

## 8️⃣ 量词可以当「的」用

粤语量词能直接放在名词前表特指，还能替代「嘅」：

- **本**书好好睇。（**这本**书很好看。）
- 我**部**手机冇电。（我**的**手机没电。）——量词「部」直接表达所属

## 🎯 综合演练：普通话 → 粤语

试着自己翻译，再看答案（粤拼可去 [words.hk](https://words.hk/) 逐字查听）：

1. 我吃了饭，你呢？ → 我食咗饭喇，你呢？
2. 给我看一下你的手机。 → 畀你部手机我睇下。
3. 今天比昨天冷，多穿点衣服。 → 今日冻过寻日，着多啲衫。
4. 你到底去不去？ → 你去唔去㗎？
5. 我没去过香港。 → 我冇去过香港。
